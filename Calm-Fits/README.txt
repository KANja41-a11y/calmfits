Calm Fits
=========

Aesthetic & calm outfit website.

How to use:
1. Extract the zip
2. Open index.html in Chrome / Safari / Firefox

Features:
- Browse by category
- Search outfits
- Favorite + named collections
- Language toggle EN / IN
- Music player: Ghost by Yel
- Soft bubble cursor
- Soft transparent wallpapers that change by category

Your photos:
Cute: Kawaii, Korean Casual, Y2K Cute, College Girl, Comfy Cute, Graphic Tee Outfit, Preppy, Soft Girl
Pretty: Cottagecore, Elegant, Fairycore, Feminine, Balletcore, Coquette, Princesscore, Romantic

Wallpapers:
- All view → soft flower field (wallpaper)
- Cute category → flower window light
- Pretty category → garden pavilion flowers

Data is saved in your browser (localStorage).

Enjoy ☁️
